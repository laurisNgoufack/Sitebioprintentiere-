# Site Bioprint

Site vitrine statique organise autour d'une racine simple et de dossiers dedies.

## Architecture

- `index.html` : page d'accueil.
- `pages/` : pages internes du site.
- `pages/services/` : pages des prestations.
- `assets/css/` : CSS compile et servi par les pages.
- `assets/js/` : scripts JavaScript du site.
- `assets/images/` : images publiques.
- `assets/vendor/` : bibliotheques tierces versionnees avec le site.
- `src/scss/` : sources Sass.

## Commandes

```bash
npm run build:styles
npm run watch:styles
```
